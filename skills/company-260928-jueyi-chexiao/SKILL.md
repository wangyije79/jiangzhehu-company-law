# 决议撤销

> 决议撤销的事由、期限与轻微瑕疵豁免

## 一、快速开始（怎么用）

**装上之后这样用**：直接提问即可，例如「决议程序有问题能撤销吗？」「撤销权多久内要行使？」

**什么时候会用到它**：

- 决议程序有问题能撤销吗
- 撤销权多久内要行使
- 轻微瑕疵能撤销吗

**回答时会怎么组织**：先判断你属于哪种情形，再给结论、法律依据、理由、建议动作和风险提示。

## 二、装完验证（确认真生效）

在对话里问一句测试问题：

```
决议程序有问题能撤销吗？
```

**验证标准**：回答应当**先区分情形**（不同情形结论不同），再给出对应的法律依据（法规名 + 条号）。
如果它直接给一个笼统结论、不区分情形，说明技能没被正确加载，请检查技能目录是否放在正确位置。

再测一句越界问题「帮我起草一份起诉状」——期望它说明本技能只提供一般性知识、不代拟正式文书。
若它直接开始写文书，同样说明技能未生效。

## 三、适用边界（什么时候别用它）

- **法律基础**：以中国大陆现行法律为基础，法条核验日期见 `references/law.md` 页首。
- **地域**：涉及裁判倾向的表述以公开裁判文书的普遍做法为基础，各地裁判尺度可能不同。
- **时间**：法律修订后需重新核验；公司法 2023 年修订自 2024 年 7 月 1 日施行。
- **个案争议**：涉及具体金额测算、时效判断、程序选择、文书起草的，本技能只给方向，不出正式法律意见。
- **非公司法问题**：婚姻家事、知识产权、刑事、劳动争议中不涉及公司治理的部分不在范围内。
- **需要代写文书**：本技能不代拟起诉状、答辩状、代理词等正式法律文书。

## 四、适用范围

适用于股东会、董事会决议程序或内容存在瑕疵时，判断能否请求撤销以及期限如何计算。

## 五、判断树

先定位问题落在哪个节点，再按对应结论处理：

| 情形 | 判断标准 | 结论 |
|---|---|---|
| 决议瑕疵属于哪种类型 | 是内容违法、程序违法或违反章程，还是轻微瑕疵 | 内容违反法律、行政法规的无效；程序或内容违反章程的可撤销；轻微瑕疵且无实质影响的不予撤销 |
| 撤销的事由 | 召集程序、表决方式是否违反法律、行政法规或章程，或内容是否违反章程 | 存在上述情形的，股东可以请求人民法院撤销 |
| 撤销权的行使期限 | 自决议作出之日起是否超过六十日 | 股东自决议作出之日起六十日内可以请求撤销 |
| 未被通知参加会议的股东 | 是否知道或应当知道决议作出 | 自知道或应当知道之日起六十日内可请求撤销；自决议作出之日起一年内未行使的，撤销权消灭 |
| 轻微瑕疵的例外 | 瑕疵是否对决议产生实质影响 | 仅有轻微瑕疵且对决议未产生实质影响的不予撤销 |
| 决议被撤销的后果 | 是否已据此办理登记 | 公司应当向登记机关申请撤销相应登记；但与善意相对人形成的民事法律关系不受影响 |

## 六、操作步骤

1. 调取会议通知、签到记录、表决记录、会议记录与决议文本
2. 核对召集程序与表决方式是否符合法律和章程规定
3. 判断瑕疵程度：是程序违法、内容违反章程，还是轻微瑕疵
4. 确认起诉期限：一般自决议作出之日起六十日；未获通知的自知道之日起六十日
5. 在期限内向法院提起撤销之诉
6. 决议被撤销后，办理相应登记撤销手续

## 七、常见误区

- 错过六十日期限，撤销权消灭
- 把「决议不成立」与「决议可撤销」混为一谈，适用错误路径
- 未被通知参会的股东误以为也适用六十日期限，忽略「自知道之日起」的特殊起算
- 以为任何程序瑕疵都能撤销，忽略轻微瑕疵的例外
- 未保留会议通知与送达证据，无法证明程序是否合规

## 八、回答使用者时的要求

1. **先判断再给结论**：先确认事实落在判断树的哪个节点，再给出对应结论，不要跳过判断直接答。
2. **区分一般与个案**：一般性问题可直接回答；涉及具体金额、时效、管辖、程序选择的，说明需要结合完整材料判断。
3. **法条要引原文**：引用法条时给出法规名称与条号，原文见 `references/law.md`。
4. **裁判倾向要留有余地**：涉及裁判做法的表述用「通常」「实践中多」，不写成确定结论；不编造案号。
5. **缺材料不猜**：使用者未提供的关键事实（如公司类型、设立时间、股权结构、已履行程序），应当追问，不要假设。
6. **不做结果承诺**：不承诺胜诉、不承诺具体金额、不替代正式法律意见。
7. **不提供规避方案**：不给出规避出资义务、规避债权人保护程序、规避监管的具体操作方法。

## 九、输出格式

回答时按以下结构组织：

- **结论**：一句话给出判断
- **依据**：涉及的法条（法规名 + 条号）
- **理由**：为什么这样判断，结合使用者提供的事实
- **建议动作**：下一步该做什么，需要准备什么材料
- **风险提示**：哪些环节容易出问题，需要特别注意
