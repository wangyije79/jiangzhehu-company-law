# 检查表

## 材料与程序自查

- [ ] 会议通知及送达凭证（含通知日期）
- [ ] 会议签到记录
- [ ] 表决记录与计票结果
- [ ] 会议记录与决议文本
- [ ] 公司章程（关于召集与表决的规定）
- [ ] 决议作出日期的证明
- [ ] 股东是否被通知参加会议的证据

## 回答使用者时的自查

- [ ] 是否先做了事实定位，再给结论
- [ ] 是否区分了一般问题与个案问题
- [ ] 引用法条是否给了法规名与条号
- [ ] 裁判倾向表述是否留有余地、是否避免编造案号
- [ ] 关键事实缺失时是否追问而非假设
- [ ] 是否避免了胜诉承诺与具体金额承诺
- [ ] 是否避免了规避义务或规避监管的操作建议
- [ ] 涉及个案争议时是否提示了咨询律师
