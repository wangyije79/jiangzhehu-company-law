# 股权对外转让

> 对外转让的通知义务与优先购买权

## 一、快速开始（怎么用）

**装上之后这样用**：直接提问即可，例如「股权能随便卖给外人吗？」「其他股东的优先购买权怎么行使？」

**什么时候会用到它**：

- 股权能随便卖给外人吗
- 其他股东的优先购买权怎么行使
- 不通知就转让有效吗

**回答时会怎么组织**：先判断你属于哪种情形，再给结论、法律依据、理由、建议动作和风险提示。

## 二、装完验证（确认真生效）

在对话里问一句测试问题：

```
股权能随便卖给外人吗？
```

**验证标准**：回答应当**先区分情形**（不同情形结论不同），再给出对应的法律依据（法规名 + 条号）。
如果它直接给一个笼统结论、不区分情形，说明技能没被正确加载，请检查技能目录是否放在正确位置。

再测一句越界问题「帮我起草一份起诉状」——期望它说明本技能只提供一般性知识、不代拟正式文书。
若它直接开始写文书，同样说明技能未生效。

## 三、适用边界（什么时候别用它）

- **法律基础**：以中国大陆现行法律为基础，法条核验日期见 `references/law.md` 页首。
- **地域**：涉及裁判倾向的表述以公开裁判文书的普遍做法为基础，各地裁判尺度可能不同。
- **时间**：法律修订后需重新核验；公司法 2023 年修订自 2024 年 7 月 1 日施行。
- **个案争议**：涉及具体金额测算、时效判断、程序选择、文书起草的，本技能只给方向，不出正式法律意见。
- **非公司法问题**：婚姻家事、知识产权、刑事、劳动争议中不涉及公司治理的部分不在范围内。
- **需要代写文书**：本技能不代拟起诉状、答辩状、代理词等正式法律文书。

## 四、适用范围

适用于有限责任公司股东向股东以外的人转让股权的情形，判断通知义务、优先购买权以及公司章程另有约定的处理。

## 五、判断树

先定位问题落在哪个节点，再按对应结论处理：

| 情形 | 判断标准 | 结论 |
|---|---|---|
| 转让对象是股东还是股东以外的人 | 受让方是否为公司现有股东 | 股东之间可以相互转让；向股东以外的人转让需履行通知义务 |
| 向股东以外的人转让需履行什么程序 | 是否书面通知其他股东并载明转让条件 | 应当将转让的数量、价格、支付方式和期限等事项书面通知其他股东 |
| 其他股东的优先购买权 | 是否在同等条件下行使 | 其他股东在同等条件下有优先购买权 |
| 答复期限 | 其他股东自接到书面通知之日起三十日内是否答复 | 三十日内未答复的，视为放弃优先购买权 |
| 多个股东都行使优先购买权 | 协商能否达成一致 | 协商确定购买比例；协商不成的，按转让时各自的出资比例行使 |
| 章程对股权转让另有约定 | 章程是否有特别规定 | 公司章程对股权转让另有规定的，从其规定 |

## 六、操作步骤

1. 确认受让方身份，判断是否属于对外转让
2. 查阅章程关于股权转让的特别约定（优先于法定规则适用）
3. 拟制书面转让通知，载明数量、价格、支付方式与期限
4. 向全体其他股东送达通知，留存送达凭证与日期
5. 等待三十日答复期，记录各股东的答复情况
6. 多个股东主张优先购买的，协商比例；协商不成的按出资比例
7. 签署转让协议，办理名册变更与工商变更登记

## 七、常见误区

- 未书面通知其他股东，直接与外部受让人签约
- 通知中未载明价格、支付方式等条件，导致「同等条件」无法判断
- 忽略章程可能对股权转让作出的特别约定
- 三十日期限计算错误（应自接到书面通知之日起算）
- 多个股东主张优先购买时，未按出资比例处理而随意确定

## 八、回答使用者时的要求

1. **先判断再给结论**：先确认事实落在判断树的哪个节点，再给出对应结论，不要跳过判断直接答。
2. **区分一般与个案**：一般性问题可直接回答；涉及具体金额、时效、管辖、程序选择的，说明需要结合完整材料判断。
3. **法条要引原文**：引用法条时给出法规名称与条号，原文见 `references/law.md`。
4. **裁判倾向要留有余地**：涉及裁判做法的表述用「通常」「实践中多」，不写成确定结论；不编造案号。
5. **缺材料不猜**：使用者未提供的关键事实（如公司类型、设立时间、股权结构、已履行程序），应当追问，不要假设。
6. **不做结果承诺**：不承诺胜诉、不承诺具体金额、不替代正式法律意见。
7. **不提供规避方案**：不给出规避出资义务、规避债权人保护程序、规避监管的具体操作方法。

## 九、输出格式

回答时按以下结构组织：

- **结论**：一句话给出判断
- **依据**：涉及的法条（法规名 + 条号）
- **理由**：为什么这样判断，结合使用者提供的事实
- **建议动作**：下一步该做什么，需要准备什么材料
- **风险提示**：哪些环节容易出问题，需要特别注意
