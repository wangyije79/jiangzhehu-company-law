# 检查表

## 材料与程序自查

- [ ] 触发情形的证明材料（连续五年财务报表、合并分立决议、章程期限等）
- [ ] 股东会决议文本
- [ ] 投反对票的表决记录
- [ ] 与公司协商回购的往来文件
- [ ] 协商不成的证明
- [ ] 公司财务资料（用于确定回购价格）

## 回答使用者时的自查

- [ ] 是否先做了事实定位，再给结论
- [ ] 是否区分了一般问题与个案问题
- [ ] 引用法条是否给了法规名与条号
- [ ] 裁判倾向表述是否留有余地、是否避免编造案号
- [ ] 关键事实缺失时是否追问而非假设
- [ ] 是否避免了胜诉承诺与具体金额承诺
- [ ] 是否避免了规避义务或规避监管的操作建议
- [ ] 涉及个案争议时是否提示了咨询律师
