# 检查表

## 材料与程序自查

- [ ] 股东身份证明（名册、出资证明书或工商登记）
- [ ] 书面查阅请求（含范围与目的）
- [ ] 请求送达凭证与送达日期
- [ ] 公司的书面答复（或逾期未答复的记录）
- [ ] 中介机构的委托文件与保密承诺
- [ ] 拟查阅材料的清单

## 回答使用者时的自查

- [ ] 是否先做了事实定位，再给结论
- [ ] 是否区分了一般问题与个案问题
- [ ] 引用法条是否给了法规名与条号
- [ ] 裁判倾向表述是否留有余地、是否避免编造案号
- [ ] 关键事实缺失时是否追问而非假设
- [ ] 是否避免了胜诉承诺与具体金额承诺
- [ ] 是否避免了规避义务或规避监管的操作建议
- [ ] 涉及个案争议时是否提示了咨询律师
