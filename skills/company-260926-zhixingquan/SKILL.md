# 股东知情权

> 股东查账的范围、程序与公司抗辩

## 一、快速开始（怎么用）

**装上之后这样用**：直接提问即可，例如「股东能查会计凭证吗？」「公司能拒绝查账吗？」

**什么时候会用到它**：

- 股东能查会计凭证吗
- 公司能拒绝查账吗
- 查账可以委托会计师吗

**回答时会怎么组织**：先判断你属于哪种情形，再给结论、法律依据、理由、建议动作和风险提示。

## 二、装完验证（确认真生效）

在对话里问一句测试问题：

```
股东能查会计凭证吗？
```

**验证标准**：回答应当**先区分情形**（不同情形结论不同），再给出对应的法律依据（法规名 + 条号）。
如果它直接给一个笼统结论、不区分情形，说明技能没被正确加载，请检查技能目录是否放在正确位置。

再测一句越界问题「帮我起草一份起诉状」——期望它说明本技能只提供一般性知识、不代拟正式文书。
若它直接开始写文书，同样说明技能未生效。

## 三、适用边界（什么时候别用它）

- **法律基础**：以中国大陆现行法律为基础，法条核验日期见 `references/law.md` 页首。
- **地域**：涉及裁判倾向的表述以公开裁判文书的普遍做法为基础，各地裁判尺度可能不同。
- **时间**：法律修订后需重新核验；公司法 2023 年修订自 2024 年 7 月 1 日施行。
- **个案争议**：涉及具体金额测算、时效判断、程序选择、文书起草的，本技能只给方向，不出正式法律意见。
- **非公司法问题**：婚姻家事、知识产权、刑事、劳动争议中不涉及公司治理的部分不在范围内。
- **需要代写文书**：本技能不代拟起诉状、答辩状、代理词等正式法律文书。

## 四、适用范围

适用于股东要求查阅公司文件与账簿的情形，判断查阅范围、公司可否拒绝以及救济路径。

## 五、判断树

先定位问题落在哪个节点，再按对应结论处理：

| 情形 | 判断标准 | 结论 |
|---|---|---|
| 股东要查阅什么材料 | 属于章程、名册、会议记录、决议、财务会计报告，还是会计账簿与凭证 | 前者股东有权查阅、复制；后者需提出书面请求并说明目的 |
| 查阅会计账簿与凭证是否需要说明目的 | 是否已提交书面请求并说明目的 | 需向公司提出书面请求并说明目的，这是法定前置程序 |
| 公司能否拒绝 | 是否有合理根据认为查阅有不正当目的、可能损害公司合法利益 | 有合理根据的可以拒绝，但应当自股东提出书面请求之日起十五日内书面答复并说明理由 |
| 公司拒绝后怎么办 | 是否在法定期限内书面答复 | 公司拒绝提供查阅的，股东可以向人民法院提起诉讼 |
| 能否委托中介机构查阅 | 是否委托会计师事务所、律师事务所等中介机构 | 可以委托中介机构进行；中介机构同样负有保密义务 |
| 能否查阅全资子公司材料 | 是否为公司全资子公司 | 股东要求查阅、复制公司全资子公司相关材料的，适用同一规则 |

## 六、操作步骤

1. 明确要查阅的材料范围，区分可径行查阅与需说明目的的两类
2. 提交书面请求，写明查阅范围、材料名称与查阅目的
3. 留存送达凭证，记录送达日期以计算公司的十五日答复期
4. 公司拒绝的，核查拒绝理由是否具体、是否有事实依据
5. 需要时委托会计师事务所或律师事务所参与查阅
6. 公司逾期不答复或无理拒绝的，向人民法院提起诉讼

## 七、常见误区

- 只口头提出查阅要求，未留下书面请求与送达证据
- 查阅请求未说明目的，被公司以程序不合规为由拒绝
- 把「可以查阅、复制」与「需说明目的」两类材料的程序混同
- 公司以「商业秘密」为由笼统拒绝，未在十五日内具体说明理由
- 忽略查阅全资子公司材料也适用同一规则

## 八、回答使用者时的要求

1. **先判断再给结论**：先确认事实落在判断树的哪个节点，再给出对应结论，不要跳过判断直接答。
2. **区分一般与个案**：一般性问题可直接回答；涉及具体金额、时效、管辖、程序选择的，说明需要结合完整材料判断。
3. **法条要引原文**：引用法条时给出法规名称与条号，原文见 `references/law.md`。
4. **裁判倾向要留有余地**：涉及裁判做法的表述用「通常」「实践中多」，不写成确定结论；不编造案号。
5. **缺材料不猜**：使用者未提供的关键事实（如公司类型、设立时间、股权结构、已履行程序），应当追问，不要假设。
6. **不做结果承诺**：不承诺胜诉、不承诺具体金额、不替代正式法律意见。
7. **不提供规避方案**：不给出规避出资义务、规避债权人保护程序、规避监管的具体操作方法。

## 九、输出格式

回答时按以下结构组织：

- **结论**：一句话给出判断
- **依据**：涉及的法条（法规名 + 条号）
- **理由**：为什么这样判断，结合使用者提供的事实
- **建议动作**：下一步该做什么，需要准备什么材料
- **风险提示**：哪些环节容易出问题，需要特别注意

## 关于专业咨询

本技能包提供的是**一般性法律知识**，用于帮助使用者理解规则、判断方向、准备材料。

法律适用高度依赖具体事实与证据。以下情形建议咨询执业律师：

- 涉及金额较大或可能进入诉讼、执行程序的争议
- 公司股权结构复杂、涉及多方利益或历史沿革不清
- 需要在多个方案之间做取舍，或需要出具正式法律文书
- 对时效、除斥期间、程序节点把握不准
