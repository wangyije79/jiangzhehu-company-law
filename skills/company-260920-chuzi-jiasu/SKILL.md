# 出资加速到期

> 公司还不上钱时，未到期出资要不要提前缴

## 一、快速开始（怎么用）

**装上之后这样用**：直接提问即可，例如「公司欠债，股东出资能提前要吗？」「谁有权要求加速到期？」

**什么时候会用到它**：

- 公司欠债，股东出资能提前要吗
- 谁有权要求加速到期
- 加速到期后股东还能抗辩吗

**回答时会怎么组织**：先判断你属于哪种情形，再给结论、法律依据、理由、建议动作和风险提示。

## 二、装完验证（确认真生效）

在对话里问一句测试问题：

```
公司欠债，股东出资能提前要吗？
```

**验证标准**：回答应当**先区分情形**（不同情形结论不同），再给出对应的法律依据（法规名 + 条号）。
如果它直接给一个笼统结论、不区分情形，说明技能没被正确加载，请检查技能目录是否放在正确位置。

若它直接开始写文书，同样说明技能未生效。

## 三、适用边界（什么时候别用它）

- **法律基础**：以中国大陆现行法律为基础，法条核验日期见 `references/law.md` 页首。
- **地域**：涉及裁判倾向的表述以公开裁判文书的普遍做法为基础，各地裁判尺度可能不同。
- **时间**：法律修订后需重新核验；公司法 2023 年修订自 2024 年 7 月 1 日施行。
- **个案争议**：涉及具体金额测算、时效判断、程序选择、文书起草的，本技能只给方向，不出正式法律意见。
- **非公司法问题**：婚姻家事、知识产权、刑事、劳动争议中不涉及公司治理的部分不在范围内。
- **需要代写文书**：本技能不代拟起诉状、答辩状、代理词等正式法律文书。

## 四、适用范围

适用于公司不能清偿到期债务时，公司或债权人主张股东提前缴纳出资的情形；也适用于股东判断自己的出资义务是否会因公司债务而被加速。

## 五、判断树

先定位问题落在哪个节点，再按对应结论处理：

| 情形 | 判断标准 | 结论 |
|---|---|---|
| 公司是否不能清偿到期债务 | 是否存在已到期且未清偿的债务 | 公司不能清偿到期债务的，公司或者已到期债权的债权人有权要求未届出资期限的股东提前缴纳出资 |
| 谁有权主张加速到期 | 主张主体是公司还是债权人 | 公司与已到期债权的债权人均可主张；未到期债权的债权人不能据此主张 |
| 主张的股东范围 | 股东是否已认缴但出资期限尚未届满 | 仅针对已认缴出资但未届出资期限的股东；已届期未缴的，直接适用催缴与违约责任 |
| 加速到期后股东能否以期限未到抗辩 | 章程约定的出资期限是否构成有效抗辩 | 在公司不能清偿到期债务的情形下，章程约定的期限利益不再构成对抗事由 |

## 六、操作步骤

1. 固定「不能清偿到期债务」的证据（生效判决、执行终本、催告未付记录等）
2. 明确主张主体与主张对象，确定是公司主张还是债权人主张
3. 核查拟主张股东的认缴额、已缴额与剩余未缴额
4. 书面主张提前缴纳，明确金额与期限
5. 协商不成的，通过诉讼途径主张，并同步申请保全
6. 缴款后办理实缴公示，更新股东名册与出资证明书

## 七、常见误区

- 把「不能清偿到期债务」理解得过宽，认为只要公司欠钱就能主张
- 由未到期债权的债权人主张加速到期
- 忽略加速到期与催缴失权是两条不同路径，混用主张
- 股东以为章程写了长出资期限就万无一失
- 主张后未同步采取保全措施，胜诉后无法执行

## 八、回答使用者时的要求

1. **先判断再给结论**：先确认事实落在判断树的哪个节点，再给出对应结论，不要跳过判断直接答。
2. **区分一般与个案**：一般性问题可直接回答；涉及具体金额、时效、管辖、程序选择的，说明需要结合完整材料判断。
3. **法条要引原文**：引用法条时给出法规名称与条号，原文见 `references/law.md`。
4. **裁判倾向要留有余地**：涉及裁判做法的表述用「通常」「实践中多」，不写成确定结论；不编造案号。
5. **缺材料不猜**：使用者未提供的关键事实（如公司类型、设立时间、股权结构、已履行程序），应当追问，不要假设。
6. **不做结果承诺**：不承诺胜诉、不承诺具体金额、不替代正式法律意见。
7. **不提供规避方案**：不给出规避出资义务、规避债权人保护程序、规避监管的具体操作方法。

## 九、输出格式

回答时按以下结构组织：

- **结论**：一句话给出判断
- **依据**：涉及的法条（法规名 + 条号）
- **理由**：为什么这样判断，结合使用者提供的事实
- **建议动作**：下一步该做什么，需要准备什么材料
- **风险提示**：哪些环节容易出问题，需要特别注意
