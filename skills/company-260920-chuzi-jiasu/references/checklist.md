# 检查表

## 材料与程序自查

- [ ] 证明公司不能清偿到期债务的材料
- [ ] 股东认缴与实缴的完整记录（章程、出资证明书、银行流水）
- [ ] 债权凭证与到期日证明
- [ ] 主张通知的书面送达记录
- [ ] 执行案件的相关文书（如已进入执行）

## 回答使用者时的自查

- [ ] 是否先做了事实定位，再给结论
- [ ] 是否区分了一般问题与个案问题
- [ ] 引用法条是否给了法规名与条号
- [ ] 裁判倾向表述是否留有余地、是否避免编造案号
- [ ] 关键事实缺失时是否追问而非假设
- [ ] 是否避免了胜诉承诺与具体金额承诺
- [ ] 是否避免了规避义务或规避监管的操作建议
- [ ] 涉及个案争议时是否提示了咨询律师
