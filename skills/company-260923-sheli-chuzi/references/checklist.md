# 检查表

## 材料与程序自查

- [ ] 设立时的公司章程与出资协议
- [ ] 验资报告或出资凭证
- [ ] 非货币出资的评估报告
- [ ] 非货币财产的权属转移凭证
- [ ] 各股东实际缴款的银行凭证
- [ ] 公司设立时的股东名册

## 回答使用者时的自查

- [ ] 是否先做了事实定位，再给结论
- [ ] 是否区分了一般问题与个案问题
- [ ] 引用法条是否给了法规名与条号
- [ ] 裁判倾向表述是否留有余地、是否避免编造案号
- [ ] 关键事实缺失时是否追问而非假设
- [ ] 是否避免了胜诉承诺与具体金额承诺
- [ ] 是否避免了规避义务或规避监管的操作建议
- [ ] 涉及个案争议时是否提示了咨询律师
