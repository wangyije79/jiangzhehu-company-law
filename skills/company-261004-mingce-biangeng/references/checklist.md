# 检查表

## 材料与程序自查

- [ ] 股权转让协议
- [ ] 请求变更股东名册的书面通知与送达凭证
- [ ] 变更后的股东名册
- [ ] 新签发的出资证明书
- [ ] 修改后的公司章程
- [ ] 工商变更登记材料
- [ ] 公司的答复或逾期未答复记录

## 回答使用者时的自查

- [ ] 是否先做了事实定位，再给结论
- [ ] 是否区分了一般问题与个案问题
- [ ] 引用法条是否给了法规名与条号
- [ ] 裁判倾向表述是否留有余地、是否避免编造案号
- [ ] 关键事实缺失时是否追问而非假设
- [ ] 是否避免了胜诉承诺与具体金额承诺
- [ ] 是否避免了规避义务或规避监管的操作建议
- [ ] 涉及个案争议时是否提示了咨询律师
