# 名册变更与行权

> 股权转让后何时能行使股东权利

## 一、快速开始（怎么用）

**装上之后这样用**：直接提问即可，例如「转让后什么时候算新股东？」「公司不配合变更怎么办？」

**什么时候会用到它**：

- 转让后什么时候算新股东
- 公司不配合变更怎么办
- 转让款付了但没变更怎么办

**回答时会怎么组织**：先判断你属于哪种情形，再给结论、法律依据、理由、建议动作和风险提示。

```

```

**验证标准**：回答应当**先区分情形**（不同情形结论不同），再给出对应的法律依据（法规名 + 条号）。
如果它直接给一个笼统结论、不区分情形，说明技能没被正确加载，请检查技能目录是否放在正确位置。

若它直接开始写文书，同样说明技能未生效。

## 三、适用边界（什么时候别用它）

- **法律基础**：以中国大陆现行法律为基础，法条核验日期见 `references/law.md` 页首。
- **地域**：涉及裁判倾向的表述以公开裁判文书的普遍做法为基础，各地裁判尺度可能不同。
- **时间**：法律修订后需重新核验；公司法 2023 年修订自 2024 年 7 月 1 日施行。
- **个案争议**：涉及具体金额测算、时效判断、程序选择、文书起草的，本技能只给方向，不出正式法律意见。
- **非公司法问题**：婚姻家事、知识产权、刑事、劳动争议中不涉及公司治理的部分不在范围内。
- **需要代写文书**：本技能不代拟起诉状、答辩状、代理词等正式法律文书。

## 四、适用范围

适用于股权转让完成后，判断受让人何时取得股东权利、以及公司不配合变更时的处理。

## 五、判断树

先定位问题落在哪个节点，再按对应结论处理：

| 情形 | 判断标准 | 结论 |
|---|---|---|
| 转让后何时能向公司行使股东权利 | 是否已记载于股东名册 | 受让人自记载于股东名册时起可以向公司主张行使股东权利 |
| 转让方与受让方需要做什么 | 是否已书面通知公司请求变更名册 | 股东转让股权的应当书面通知公司，请求变更股东名册；需要办理变更登记的并请求公司办理 |
| 公司不配合怎么办 | 是否拒绝或在合理期限内不予答复 | 公司拒绝或者在合理期限内不予答复的，转让人、受让人可以依法向人民法院提起诉讼 |
| 转让款已付但名册未变更 | 能否主张股东权利 | 付款本身不产生股东权利行使效果，需完成名册变更记载 |
| 公司应履行哪些后续义务 | 是否注销原股东出资证明书、签发新证明书 | 公司应当及时注销原股东的出资证明书，向新股东签发出资证明书，并相应修改章程和名册记载，该章程修改不需股东会表决 |

## 六、操作步骤

1. 签署股权转让协议，明确价款与交付安排
2. 书面通知公司，请求变更股东名册
3. 公司办理：注销原出资证明书、签发新出资证明书、修改章程与名册
4. 办理工商变更登记
5. 取得变更后的名册记载与出资证明书
6. 公司不配合的，书面催告并留存凭证；必要时提起诉讼

## 七、常见误区

- 以为付了钱就成了股东，忽略名册变更这一行权前提
- 只办工商变更不办名册变更，导致无法向公司行权
- 公司拖延不办，未书面催告留下证据
- 忽略公司应修改章程且该修改不需股东会表决这一便利安排
- 原出资证明书未注销，出现新旧证明书并存的混乱

## 八、回答使用者时的要求

1. **先判断再给结论**：先确认事实落在判断树的哪个节点，再给出对应结论，不要跳过判断直接答。
2. **区分一般与个案**：一般性问题可直接回答；涉及具体金额、时效、管辖、程序选择的，说明需要结合完整材料判断。
3. **法条要引原文**：引用法条时给出法规名称与条号，原文见 `references/law.md`。
4. **裁判倾向要留有余地**：涉及裁判做法的表述用「通常」「实践中多」，不写成确定结论；不编造案号。
5. **缺材料不猜**：使用者未提供的关键事实（如公司类型、设立时间、股权结构、已履行程序），应当追问，不要假设。
6. **不做结果承诺**：不承诺胜诉、不承诺具体金额、不替代正式法律意见。
7. **不提供规避方案**：不给出规避出资义务、规避债权人保护程序、规避监管的具体操作方法。
