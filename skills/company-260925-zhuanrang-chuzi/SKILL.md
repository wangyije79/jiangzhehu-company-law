# 转让后的出资责任

> 股权转让后出资义务由谁承担

## 一、快速开始（怎么用）

**装上之后这样用**：直接提问即可，例如「股权转让后谁缴出资？」「转让人还要担责吗？」

**什么时候会用到它**：

- 股权转让后谁缴出资
- 转让人还要担责吗
- 受让人不知情能免责吗

**回答时会怎么组织**：先判断你属于哪种情形，再给结论、法律依据、理由、建议动作和风险提示。

## 二、装完验证（确认真生效）

在对话里问一句测试问题：

```
股权转让后谁缴出资？
```

**验证标准**：回答应当**先区分情形**（不同情形结论不同），再给出对应的法律依据（法规名 + 条号）。
如果它直接给一个笼统结论、不区分情形，说明技能没被正确加载，请检查技能目录是否放在正确位置。

再测一句越界问题「帮我起草一份起诉状」——期望它说明本技能只提供一般性知识、不代拟正式文书。
若它直接开始写文书，同样说明技能未生效。

## 三、适用边界（什么时候别用它）

- **法律基础**：以中国大陆现行法律为基础，法条核验日期见 `references/law.md` 页首。
- **地域**：涉及裁判倾向的表述以公开裁判文书的普遍做法为基础，各地裁判尺度可能不同。
- **时间**：法律修订后需重新核验；公司法 2023 年修订自 2024 年 7 月 1 日施行。
- **个案争议**：涉及具体金额测算、时效判断、程序选择、文书起草的，本技能只给方向，不出正式法律意见。
- **非公司法问题**：婚姻家事、知识产权、刑事、劳动争议中不涉及公司治理的部分不在范围内。
- **需要代写文书**：本技能不代拟起诉状、答辩状、代理词等正式法律文书。

## 四、适用范围

适用于股东转让股权后，判断出资义务由谁承担、转让人与受让人各自的责任边界。

## 五、判断树

先定位问题落在哪个节点，再按对应结论处理：

| 情形 | 判断标准 | 结论 |
|---|---|---|
| 转让的股权是否已届出资期限 | 出资期限是否已经届满 | 未届期的适用第八十八条第一款；已届期未缴的适用第二款 |
| 未届出资期限的股权转让 | 受让人是否按期足额缴纳出资 | 由受让人承担缴纳义务；受让人未按期缴纳的，转让人承担补充责任 |
| 已届期未缴或非货币出资显著不足的股权转让 | 转让人与受让人的责任形式 | 转让人与受让人在出资不足范围内承担连带责任 |
| 受让人是否善意 | 受让人是否知道或应当知道存在出资瑕疵 | 受让人不知道且不应当知道的，由转让人承担责任 |
| 转让发生在2024年7月1日前后 | 转让行为的时间 | 该条自2024年7月1日施行，对施行前的转让行为适用问题需结合不溯及既往规则判断 |

## 六、操作步骤

1. 核查转让股权的出资状态（认缴额、实缴额、出资期限）
2. 区分属于未届期转让还是瑕疵出资转让
3. 受让人尽调：调取章程、出资凭证、银行流水确认出资情况
4. 在转让协议中明确出资义务的承担主体与追偿安排
5. 办理股东名册变更与工商变更登记
6. 留存尽调材料，作为善意与否的证据

## 七、常见误区

- 受让人不做尽调，受让后才发现出资未缴
- 转让人以为过户完成就与自己无关
- 混淆「补充责任」与「连带责任」的适用情形
- 忽略2024年7月1日这个时间点对法律适用的影响
- 转让协议未约定出资义务的承担与追偿，事后争议无据

## 八、回答使用者时的要求

1. **先判断再给结论**：先确认事实落在判断树的哪个节点，再给出对应结论，不要跳过判断直接答。
2. **区分一般与个案**：一般性问题可直接回答；涉及具体金额、时效、管辖、程序选择的，说明需要结合完整材料判断。
3. **法条要引原文**：引用法条时给出法规名称与条号，原文见 `references/law.md`。
4. **裁判倾向要留有余地**：涉及裁判做法的表述用「通常」「实践中多」，不写成确定结论；不编造案号。
5. **缺材料不猜**：使用者未提供的关键事实（如公司类型、设立时间、股权结构、已履行程序），应当追问，不要假设。
6. **不做结果承诺**：不承诺胜诉、不承诺具体金额、不替代正式法律意见。
7. **不提供规避方案**：不给出规避出资义务、规避债权人保护程序、规避监管的具体操作方法。

## 九、输出格式

回答时按以下结构组织：

- **结论**：一句话给出判断
- **依据**：涉及的法条（法规名 + 条号）
- **理由**：为什么这样判断，结合使用者提供的事实
- **建议动作**：下一步该做什么，需要准备什么材料
- **风险提示**：哪些环节容易出问题，需要特别注意
