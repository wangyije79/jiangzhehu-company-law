# 催缴与股东失权

> 董事会催缴义务与股东失权的适用条件

## 一、快速开始（怎么用）

**装上之后这样用**：直接提问即可，例如「股东不缴出资公司能怎么办？」「股东失权的宽限期是多久？」

**什么时候会用到它**：

- 股东不缴出资公司能怎么办
- 股东失权的宽限期是多久
- 被失权了还能救回来吗

**回答时会怎么组织**：先判断你属于哪种情形，再给结论、法律依据、理由、建议动作和风险提示。

## 三、适用边界（什么时候别用它）

- **法律基础**：以中国大陆现行法律为基础，法条核验日期见 `references/law.md` 页首。
- **地域**：涉及裁判倾向的表述以公开裁判文书的普遍做法为基础，各地裁判尺度可能不同。
- **时间**：法律修订后需重新核验；公司法 2023 年修订自 2024 年 7 月 1 日施行。
- **个案争议**：涉及具体金额测算、时效判断、程序选择、文书起草的，本技能只给方向，不出正式法律意见。
- **非公司法问题**：婚姻家事、知识产权、刑事、劳动争议中不涉及公司治理的部分不在范围内。
- **需要代写文书**：本技能不代拟起诉状、答辩状、代理词等正式法律文书。

## 四、适用范围

适用于股东未按期缴纳出资时，公司通过催缴与失权程序处理的情形；也适用于股东判断自身是否会因未缴出资而丧失股权。

## 五、判断树

先定位问题落在哪个节点，再按对应结论处理：

| 情形 | 判断标准 | 结论 |
|---|---|---|
| 股东是否未按期足额缴纳出资 | 章程规定的出资日期是否已届满 | 届满未缴的，董事会应当核查并推动公司发出书面催缴书 |
| 董事会是否履行了催缴义务 | 是否已由公司发出书面催缴书 | 未及时履行催缴义务给公司造成损失的，负有责任的董事应当承担赔偿责任 |
| 催缴书是否载明宽限期 | 宽限期是否不少于六十日 | 宽限期自公司发出催缴书之日起不得少于六十日；未载明宽限期的，不能直接进入失权程序 |
| 宽限期届满仍未缴纳 | 是否经董事会决议发出失权通知 | 经董事会决议可以发出书面失权通知，自通知发出之日起该股东丧失未缴纳出资的股权 |
| 股东对失权有异议 | 是否在接到通知之日起三十日内起诉 | 应当在三十日内向人民法院提起诉讼，逾期则失权生效 |
| 失权股权的后续处理 | 六个月内是否转让或注销 | 六个月内未转让或注销的，由其他股东按出资比例足额缴纳相应出资 |

## 六、操作步骤

1. 董事会核查全体股东的出资情况，形成书面核查记录
2. 对未按期缴纳的股东，由公司发出书面催缴书
3. 催缴书中载明宽限期（不少于六十日）与缴款账户
4. 宽限期届满仍未缴纳的，召开董事会并作出失权决议
5. 向该股东发出书面失权通知，留存送达凭证
6. 处理失权股权：依法转让，或减资注销；六个月内未完成的，由其他股东按比例缴纳
7. 办理相应变更登记与公示

## 七、常见误区

- 跳过催缴直接失权——未催缴或未给足六十日宽限期，失权程序存在瑕疵
- 董事会不履行核查与催缴义务，董事个人可能担责
- 失权通知未采用书面形式或未留存送达证据
- 股东对失权有异议却超过三十日才起诉，丧失救济机会
- 失权股权六个月内未处置，导致其他股东被动承担出资义务

## 八、回答使用者时的要求

1. **先判断再给结论**：先确认事实落在判断树的哪个节点，再给出对应结论，不要跳过判断直接答。
2. **区分一般与个案**：一般性问题可直接回答；涉及具体金额、时效、管辖、程序选择的，说明需要结合完整材料判断。
3. **法条要引原文**：引用法条时给出法规名称与条号，原文见 `references/law.md`。
4. **裁判倾向要留有余地**：涉及裁判做法的表述用「通常」「实践中多」，不写成确定结论；不编造案号。
5. **缺材料不猜**：使用者未提供的关键事实（如公司类型、设立时间、股权结构、已履行程序），应当追问，不要假设。
6. **不做结果承诺**：不承诺胜诉、不承诺具体金额、不替代正式法律意见。
7. **不提供规避方案**：不给出规避出资义务、规避债权人保护程序、规避监管的具体操作方法。

## 九、输出格式

回答时按以下结构组织：

- **结论**：一句话给出判断
- **依据**：涉及的法条（法规名 + 条号）
- **理由**：为什么这样判断，结合使用者提供的事实
- **建议动作**：下一步该做什么，需要准备什么材料
- **风险提示**：哪些环节容易出问题，需要特别注意
