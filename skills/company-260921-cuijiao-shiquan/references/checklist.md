# 检查表

## 材料与程序自查

- [ ] 董事会出资核查记录
- [ ] 书面催缴书及送达凭证
- [ ] 催缴书中的宽限期起算日与届满日记录
- [ ] 董事会关于失权的决议
- [ ] 失权通知及送达凭证
- [ ] 失权股权的处置记录（转让协议或减资程序文件）
- [ ] 变更登记与公示记录

## 回答使用者时的自查

- [ ] 是否先做了事实定位，再给结论
- [ ] 是否区分了一般问题与个案问题
- [ ] 引用法条是否给了法规名与条号
- [ ] 裁判倾向表述是否留有余地、是否避免编造案号
- [ ] 关键事实缺失时是否追问而非假设
- [ ] 是否避免了胜诉承诺与具体金额承诺
- [ ] 是否避免了规避义务或规避监管的操作建议
- [ ] 涉及个案争议时是否提示了咨询律师
