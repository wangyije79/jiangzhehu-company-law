# 抽逃出资

> 抽逃出资的认定与董监高连带责任

## 一、快速开始（怎么用）

**装上之后这样用**：直接提问即可，例如「老板从公司拿钱算抽逃出资吗？」「抽逃出资要还多少？」

**什么时候会用到它**：

- 老板从公司拿钱算抽逃出资吗
- 抽逃出资要还多少
- 董监高为什么也要赔

**回答时会怎么组织**：先判断你属于哪种情形，再给结论、法律依据、理由、建议动作和风险提示。

## 二、装完验证（确认真生效）

在对话里问一句测试问题：

```
老板从公司拿钱算抽逃出资吗？
```

**验证标准**：回答应当**先区分情形**（不同情形结论不同），再给出对应的法律依据（法规名 + 条号）。
如果它直接给一个笼统结论、不区分情形，说明技能没被正确加载，请检查技能目录是否放在正确位置。

若它直接开始写文书，同样说明技能未生效。

## 三、适用边界（什么时候别用它）

- **法律基础**：以中国大陆现行法律为基础，法条核验日期见 `references/law.md` 页首。
- **地域**：涉及裁判倾向的表述以公开裁判文书的普遍做法为基础，各地裁判尺度可能不同。
- **时间**：法律修订后需重新核验；公司法 2023 年修订自 2024 年 7 月 1 日施行。
- **个案争议**：涉及具体金额测算、时效判断、程序选择、文书起草的，本技能只给方向，不出正式法律意见。
- **非公司法问题**：婚姻家事、知识产权、刑事、劳动争议中不涉及公司治理的部分不在范围内。
- **需要代写文书**：本技能不代拟起诉状、答辩状、代理词等正式法律文书。

## 四、适用范围

适用于股东从公司取得资金是否构成抽逃出资的判断，以及抽逃出资后股东与董监高的责任承担。

## 五、判断树

先定位问题落在哪个节点，再按对应结论处理：

| 情形 | 判断标准 | 结论 |
|---|---|---|
| 股东是否从公司取得了资金或财产 | 该行为是否发生在公司成立之后 | 公司成立后股东不得抽逃出资；成立前的出资安排适用出资相关规定 |
| 该取得行为是否有合法依据 | 是否基于真实的交易、借款、分配或报酬关系 | 无合法依据或形式合法但实质无对价的，可能被认定为抽逃出资 |
| 是否履行了必要程序 | 是否经过股东会或董事会决议、是否办理相应手续 | 未履行程序的资金流出，被认定抽逃的可能性显著提高 |
| 是否损害公司或债权人利益 | 公司是否有能力清偿到期债务 | 抽逃出资导致公司不能清偿债务的，股东需在抽逃范围内承担相应责任 |
| 董监高是否负有责任 | 是否协助、默许或未尽到审核职责 | 负有责任的董事、监事、高级管理人员应当与该股东承担连带赔偿责任 |

## 六、操作步骤

1. 梳理公司成立后向股东流出的全部资金往来，逐笔标注时间、金额与事由
2. 对每笔往来核查是否有合同、决议、发票等支撑材料
3. 区分正常商业往来与无对价流出，形成初步认定意见
4. 对存在抽逃嫌疑的，要求股东返还并补正手续
5. 涉及董监高责任的，核查其在相关决策中的角色与是否尽到审核义务
6. 必要时通过诉讼主张返还与赔偿，并申请财产保全

## 七、常见误区

- 认为只要走了账、签了借款协议就不构成抽逃
- 把股东借款长期不还视为正常往来
- 忽略非货币形式的抽逃（如无偿使用公司资产、以公司名义为股东担保）
- 只追究股东责任，遗漏负有责任的董监高的连带责任
- 发现问题后未及时固定证据，导致举证困难

## 八、回答使用者时的要求

1. **先判断再给结论**：先确认事实落在判断树的哪个节点，再给出对应结论，不要跳过判断直接答。
2. **区分一般与个案**：一般性问题可直接回答；涉及具体金额、时效、管辖、程序选择的，说明需要结合完整材料判断。
3. **法条要引原文**：引用法条时给出法规名称与条号，原文见 `references/law.md`。
4. **裁判倾向要留有余地**：涉及裁判做法的表述用「通常」「实践中多」，不写成确定结论；不编造案号。
5. **缺材料不猜**：使用者未提供的关键事实（如公司类型、设立时间、股权结构、已履行程序），应当追问，不要假设。
6. **不做结果承诺**：不承诺胜诉、不承诺具体金额、不替代正式法律意见。
7. **不提供规避方案**：不给出规避出资义务、规避债权人保护程序、规避监管的具体操作方法。

## 九、输出格式

回答时按以下结构组织：

- **结论**：一句话给出判断
- **依据**：涉及的法条（法规名 + 条号）
- **理由**：为什么这样判断，结合使用者提供的事实
- **建议动作**：下一步该做什么，需要准备什么材料
- **风险提示**：哪些环节容易出问题，需要特别注意
