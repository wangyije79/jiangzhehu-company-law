# 检查表

## 材料与程序自查

- [ ] 股权结构证明（确认控股股东身份）
- [ ] 滥用权利行为的证据（决议、合同、资金流水）
- [ ] 损害结果与金额的测算材料
- [ ] 公司财务资料与评估报告
- [ ] 回购请求的书面文件与送达凭证
- [ ] 协商记录

## 回答使用者时的自查

- [ ] 是否先做了事实定位，再给结论
- [ ] 是否区分了一般问题与个案问题
- [ ] 引用法条是否给了法规名与条号
- [ ] 裁判倾向表述是否留有余地、是否避免编造案号
- [ ] 关键事实缺失时是否追问而非假设
- [ ] 是否避免了胜诉承诺与具体金额承诺
- [ ] 是否避免了规避义务或规避监管的操作建议
- [ ] 涉及个案争议时是否提示了咨询律师
