# 对外担保

> 对外担保的决议要求与越权担保效力

## 一、快速开始（怎么用）

**装上之后这样用**：直接提问即可，例如「公司担保要什么决议？」「给股东担保要谁同意？」

**什么时候会用到它**：

- 公司担保要什么决议
- 给股东担保要谁同意
- 越权担保公司要不要担责

**回答时会怎么组织**：先判断你属于哪种情形，再给结论、法律依据、理由、建议动作和风险提示。

## 二、装完验证（确认真生效）

在对话里问一句测试问题：

```
公司担保要什么决议？
```

**验证标准**：回答应当**先区分情形**（不同情形结论不同），再给出对应的法律依据（法规名 + 条号）。
如果它直接给一个笼统结论、不区分情形，说明技能没被正确加载，请检查技能目录是否放在正确位置。

再测一句越界问题「帮我起草一份起诉状」——期望它说明本技能只提供一般性知识、不代拟正式文书。
若它直接开始写文书，同样说明技能未生效。

## 三、适用边界（什么时候别用它）

- **法律基础**：以中国大陆现行法律为基础，法条核验日期见 `references/law.md` 页首。
- **地域**：涉及裁判倾向的表述以公开裁判文书的普遍做法为基础，各地裁判尺度可能不同。
- **时间**：法律修订后需重新核验；公司法 2023 年修订自 2024 年 7 月 1 日施行。
- **个案争议**：涉及具体金额测算、时效判断、程序选择、文书起草的，本技能只给方向，不出正式法律意见。
- **非公司法问题**：婚姻家事、知识产权、刑事、劳动争议中不涉及公司治理的部分不在范围内。
- **需要代写文书**：本技能不代拟起诉状、答辩状、代理词等正式法律文书。

## 四、适用范围

适用于公司为他人或为股东提供担保的情形，判断决议要求、表决回避以及越权担保的效力。

## 五、判断树

先定位问题落在哪个节点，再按对应结论处理：

| 情形 | 判断标准 | 结论 |
|---|---|---|
| 担保对象是谁 | 是为他人担保，还是为公司股东/实际控制人担保 | 为他人担保按章程规定由董事会或股东会决议；为股东或实际控制人担保必须经股东会决议 |
| 章程对担保有限额规定吗 | 是否超过章程规定的总额或单项限额 | 章程对投资或担保总额及单项数额有限额规定的，不得超过 |
| 关联股东是否回避 | 该股东或受实际控制人支配的股东是否参加表决 | 不得参加该事项表决，由出席会议的其他股东所持表决权的过半数通过 |
| 是否构成越权担保 | 决议机关或决议程序是否符合法律与章程 | 越权担保的效力需结合相对人是否善意判断 |
| 相对人是否善意 | 是否审查了决议并尽到合理审查义务 | 相对人善意时担保有效；相对人明知或应知越权的，担保对公司不发生效力 |

## 六、操作步骤

1. 确认担保对象，判断应经董事会还是股东会决议
2. 查阅章程关于担保限额与决议机关的约定
3. 关联股东回避表决，由其他股东过半数通过
4. 形成书面决议，载明担保金额、对象、期限与担保方式
5. 向相对人提供决议文件，相对人应尽合理审查义务
6. 留存决议、章程、审查记录等全套材料

## 七、常见误区

- 为股东担保只走董事会决议，未提交股东会
- 关联股东参加表决，导致决议程序违法
- 忽略章程对担保限额的约定，超限担保
- 相对人未审查决议，事后主张善意难以成立
- 把担保与投资混同，适用错误的决议要求

## 八、回答使用者时的要求

1. **先判断再给结论**：先确认事实落在判断树的哪个节点，再给出对应结论，不要跳过判断直接答。
2. **区分一般与个案**：一般性问题可直接回答；涉及具体金额、时效、管辖、程序选择的，说明需要结合完整材料判断。
3. **法条要引原文**：引用法条时给出法规名称与条号，原文见 `references/law.md`。
4. **裁判倾向要留有余地**：涉及裁判做法的表述用「通常」「实践中多」，不写成确定结论；不编造案号。
5. **缺材料不猜**：使用者未提供的关键事实（如公司类型、设立时间、股权结构、已履行程序），应当追问，不要假设。
6. **不做结果承诺**：不承诺胜诉、不承诺具体金额、不替代正式法律意见。
7. **不提供规避方案**：不给出规避出资义务、规避债权人保护程序、规避监管的具体操作方法。

## 九、输出格式

回答时按以下结构组织：

- **结论**：一句话给出判断
- **依据**：涉及的法条（法规名 + 条号）
- **理由**：为什么这样判断，结合使用者提供的事实
- **建议动作**：下一步该做什么，需要准备什么材料
- **风险提示**：哪些环节容易出问题，需要特别注意
