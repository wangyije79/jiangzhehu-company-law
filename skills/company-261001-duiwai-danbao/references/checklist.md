# 检查表

## 材料与程序自查

- [ ] 公司章程（担保条款与限额）
- [ ] 担保事项的董事会或股东会决议
- [ ] 关联股东回避表决的记录
- [ ] 表决权计算过程
- [ ] 担保合同与主债权合同
- [ ] 相对人审查决议的记录

## 回答使用者时的自查

- [ ] 是否先做了事实定位，再给结论
- [ ] 是否区分了一般问题与个案问题
- [ ] 引用法条是否给了法规名与条号
- [ ] 裁判倾向表述是否留有余地、是否避免编造案号
- [ ] 关键事实缺失时是否追问而非假设
- [ ] 是否避免了胜诉承诺与具体金额承诺
- [ ] 是否避免了规避义务或规避监管的操作建议
- [ ] 涉及个案争议时是否提示了咨询律师
