# 检查表

## 材料与程序自查

- [ ] 股东会决议（含表决权比例记录）
- [ ] 资产负债表与财产清单
- [ ] 债权人通知与公告的凭证
- [ ] 债权人申报债权的登记记录
- [ ] 债务清偿或担保安排的证明
- [ ] 变更登记或注销登记材料
- [ ] 清算报告（解散清算时）

## 回答使用者时的自查

- [ ] 是否先做了事实定位，再给结论
- [ ] 是否区分了一般问题与个案问题
- [ ] 引用法条是否给了法规名与条号
- [ ] 裁判倾向表述是否留有余地、是否避免编造案号
- [ ] 关键事实缺失时是否追问而非假设
- [ ] 是否避免了胜诉承诺与具体金额承诺
- [ ] 是否避免了规避义务或规避监管的操作建议
- [ ] 涉及个案争议时是否提示了咨询律师
