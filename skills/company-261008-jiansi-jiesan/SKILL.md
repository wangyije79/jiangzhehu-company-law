# 减资与解散清算

> 减资程序要求与解散清算的责任边界

## 一、快速开始（怎么用）

**装上之后这样用**：直接提问即可，例如「减资要通知债权人吗？」「减资后股东还要还钱吗？」

**什么时候会用到它**：

- 减资要通知债权人吗
- 减资后股东还要还钱吗
- 公司解散了债务谁承担

**回答时会怎么组织**：先判断你属于哪种情形，再给结论、法律依据、理由、建议动作和风险提示。

## 二、装完验证（确认真生效）

在对话里问一句测试问题：

```
减资要通知债权人吗？
```

**验证标准**：回答应当**先区分情形**（不同情形结论不同），再给出对应的法律依据（法规名 + 条号）。
如果它直接给一个笼统结论、不区分情形，说明技能没被正确加载，请检查技能目录是否放在正确位置。

若它直接开始写文书，同样说明技能未生效。

## 三、适用边界（什么时候别用它）

- **法律基础**：以中国大陆现行法律为基础，法条核验日期见 `references/law.md` 页首。
- **地域**：涉及裁判倾向的表述以公开裁判文书的普遍做法为基础，各地裁判尺度可能不同。
- **时间**：法律修订后需重新核验；公司法 2023 年修订自 2024 年 7 月 1 日施行。
- **个案争议**：涉及具体金额测算、时效判断、程序选择、文书起草的，本技能只给方向，不出正式法律意见。
- **非公司法问题**：婚姻家事、知识产权、刑事、劳动争议中不涉及公司治理的部分不在范围内。
- **需要代写文书**：本技能不代拟起诉状、答辩状、代理词等正式法律文书。

## 四、适用范围

适用于公司减少注册资本或解散清算的情形，判断程序要求与股东责任边界。

## 五、判断树

先定位问题落在哪个节点，再按对应结论处理：

| 情形 | 判断标准 | 结论 |
|---|---|---|
| 是减资还是解散清算 | 公司是继续存续但减少资本，还是终止并清算 | 两者程序与法律后果不同，需先区分 |
| 减资的表决要求 | 是否经代表三分之二以上表决权的股东通过 | 减少注册资本的决议应当经代表三分之二以上表决权的股东通过 |
| 减资是否需要通知债权人 | 是否履行了通知与公告程序 | 减资应当编制资产负债表及财产清单，通知债权人并进行公告 |
| 违法减资的后果 | 是否损害债权人利益 | 未依法履行通知与公告程序的减资，股东可能需在减资范围内承担责任 |
| 清算义务与责任 | 清算义务人是否依法及时清算 | 公司解散应当清算；未及时清算造成损失的，相关主体需承担相应责任 |

## 六、操作步骤

1. 判断属于减资还是解散清算，确定适用程序
2. 减资：编制资产负债表及财产清单
3. 减资：作出股东会决议（三分之二以上表决权）
4. 减资：通知债权人并进行公告，处理债权人的清偿或担保要求
5. 办理变更登记与公示
6. 解散清算：成立清算组，通知公告债权人，清理财产编制清算方案，分配剩余财产，办理注销登记

## 七、常见误区

- 减资只做决议不通知债权人，程序存在重大瑕疵
- 以为减资后就与公司债务无关
- 用减资规避出资义务，但未履行债权人保护程序
- 解散后不及时清算，导致责任扩大
- 清算中遗漏债权人，事后被追究责任

## 八、回答使用者时的要求

1. **先判断再给结论**：先确认事实落在判断树的哪个节点，再给出对应结论，不要跳过判断直接答。
2. **区分一般与个案**：一般性问题可直接回答；涉及具体金额、时效、管辖、程序选择的，说明需要结合完整材料判断。
3. **法条要引原文**：引用法条时给出法规名称与条号，原文见 `references/law.md`。
4. **裁判倾向要留有余地**：涉及裁判做法的表述用「通常」「实践中多」，不写成确定结论；不编造案号。
5. **缺材料不猜**：使用者未提供的关键事实（如公司类型、设立时间、股权结构、已履行程序），应当追问，不要假设。
6. **不做结果承诺**：不承诺胜诉、不承诺具体金额、不替代正式法律意见。
7. **不提供规避方案**：不给出规避出资义务、规避债权人保护程序、规避监管的具体操作方法。

## 九、输出格式

回答时按以下结构组织：

- **结论**：一句话给出判断
- **依据**：涉及的法条（法规名 + 条号）
- **理由**：为什么这样判断，结合使用者提供的事实
- **建议动作**：下一步该做什么，需要准备什么材料
- **风险提示**：哪些环节容易出问题，需要特别注意
