# 认缴期限调整

> 存量公司认缴期限调整的窗口期与操作

## 一、快速开始（怎么用）

**装上之后这样用**：直接提问即可，例如「2027年6月30日前公司必须做什么？」「认缴期限要调到几年内？」

**什么时候会用到它**：

- 2027年6月30日前公司必须做什么
- 认缴期限要调到几年内
- 股份公司和有限公司要求一样吗

**回答时会怎么组织**：先判断你属于哪种情形，再给结论、法律依据、理由、建议动作和风险提示。

## 二、装完验证（确认真生效）

在对话里问一句测试问题：

```
2027年6月30日前公司必须做什么？
```

**验证标准**：回答应当**先区分情形**（不同情形结论不同），再给出对应的法律依据（法规名 + 条号）。
如果它直接给一个笼统结论、不区分情形，说明技能没被正确加载，请检查技能目录是否放在正确位置。

再测一句越界问题「帮我起草一份起诉状」——期望它说明本技能只提供一般性知识、不代拟正式文书。
若它直接开始写文书，同样说明技能未生效。

## 三、适用边界（什么时候别用它）

- **法律基础**：以中国大陆现行法律为基础，法条核验日期见 `references/law.md` 页首。
- **地域**：涉及裁判倾向的表述以公开裁判文书的普遍做法为基础，各地裁判尺度可能不同。
- **时间**：法律修订后需重新核验；公司法 2023 年修订自 2024 年 7 月 1 日施行。
- **个案争议**：涉及具体金额测算、时效判断、程序选择、文书起草的，本技能只给方向，不出正式法律意见。
- **非公司法问题**：婚姻家事、知识产权、刑事、劳动争议中不涉及公司治理的部分不在范围内。
- **需要代写文书**：本技能不代拟起诉状、答辩状、代理词等正式法律文书。

## 四、适用范围

适用于2024年6月30日前登记设立的存量公司，判断认缴出资期限是否需要调整、以及如何在过渡期内完成调整；也适用于股份公司发起人判断缴足股款的时点。

## 五、判断树

先定位问题落在哪个节点，再按对应结论处理：

| 情形 | 判断标准 | 结论 |
|---|---|---|
| 公司是2024年6月30日前设立的吗 | 设立时间是否早于2024年7月1日 | 早于该日的属存量公司，适用过渡期安排；之后设立的直接适用五年认缴期 |
| 存量有限公司的剩余认缴期限有多长 | 自2027年7月1日起剩余期限是否超过五年 | 超过五年的，应当在2027年6月30日前将剩余认缴期限调整至五年以内，并记载于公司章程 |
| 公司是股份有限公司吗 | 发起人是否已缴足认购股份的股款 | 股份有限公司发起人应当在2027年6月30日前按认购股份全额缴纳股款，这才是真正的缴款大限 |
| 调整后何时要实际缴足 | 调整后的认缴期限届满日 | 股东应在调整后的认缴期限内足额缴纳，最晚可至调整之日起五年内，即理论上可至2032年，并非2027年就必须缴清 |
| 公司涉及国家利益或重大公共利益 | 是否由主管部门提出意见 | 可由国务院市场监督管理部门同意其按原出资期限出资，属例外通道 |

## 六、操作步骤

1. 确认公司设立日期，判断属于存量公司还是新设公司
2. 查阅现行章程记载的认缴出资期限，计算自2027年7月1日起的剩余期限
3. 剩余期限超过五年的，召开股东会作出调整决议（需三分之二以上表决权通过）
4. 修改公司章程相应条款，明确调整后的出资期限
5. 办理章程备案，并在国家企业信用信息公示系统完成公示
6. 按调整后的期限安排资金，留存缴款凭证

## 七、常见误区

- 把2027年6月30日误认为实缴截止日——对有限公司而言那是调整期限的截止日
- 以为股份公司也能像有限公司一样只调整期限——发起人须在2027年6月30日前缴足
- 只调整章程不办理备案，或只备案不修改章程
- 用减资规避出资义务，却未履行通知债权人的程序
- 把认缴期限调整与实缴混为一谈，向股东传达错误的资金安排时间

## 八、回答使用者时的要求

1. **先判断再给结论**：先确认事实落在判断树的哪个节点，再给出对应结论，不要跳过判断直接答。
2. **区分一般与个案**：一般性问题可直接回答；涉及具体金额、时效、管辖、程序选择的，说明需要结合完整材料判断。
3. **法条要引原文**：引用法条时给出法规名称与条号，原文见 `references/law.md`。
4. **裁判倾向要留有余地**：涉及裁判做法的表述用「通常」「实践中多」，不写成确定结论；不编造案号。
5. **缺材料不猜**：使用者未提供的关键事实（如公司类型、设立时间、股权结构、已履行程序），应当追问，不要假设。
6. **不做结果承诺**：不承诺胜诉、不承诺具体金额、不替代正式法律意见。
7. **不提供规避方案**：不给出规避出资义务、规避债权人保护程序、规避监管的具体操作方法。

## 九、输出格式

回答时按以下结构组织：

- **结论**：一句话给出判断
- **依据**：涉及的法条（法规名 + 条号）
- **理由**：为什么这样判断，结合使用者提供的事实
- **建议动作**：下一步该做什么，需要准备什么材料
- **风险提示**：哪些环节容易出问题，需要特别注意
