# 检查表

## 材料与程序自查

- [ ] 营业执照或登记信息确认的设立日期
- [ ] 现行章程中的认缴出资额、出资方式与出资期限条款
- [ ] 自2027年7月1日起的剩余认缴期限计算表
- [ ] 股东会关于调整出资期限的决议（三分之二以上表决权）
- [ ] 修改后的公司章程及备案回执
- [ ] 公示系统公示截图

## 回答使用者时的自查

- [ ] 是否先做了事实定位，再给结论
- [ ] 是否区分了一般问题与个案问题
- [ ] 引用法条是否给了法规名与条号
- [ ] 裁判倾向表述是否留有余地、是否避免编造案号
- [ ] 关键事实缺失时是否追问而非假设
- [ ] 是否避免了胜诉承诺与具体金额承诺
- [ ] 是否避免了规避义务或规避监管的操作建议
- [ ] 涉及个案争议时是否提示了咨询律师
