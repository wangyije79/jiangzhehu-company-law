# 检查表

## 材料与程序自查

- [ ] 评估报告（须有资质机构出具）
- [ ] 财产的权属证明文件
- [ ] 财产权转移凭证（过户登记、交付确认等）
- [ ] 是否存在抵押、质押等权利负担的查询记录
- [ ] 章程中的出资方式与金额条款
- [ ] 验资或出资确认材料

## 回答使用者时的自查

- [ ] 是否先做了事实定位，再给结论
- [ ] 是否区分了一般问题与个案问题
- [ ] 引用法条是否给了法规名与条号
- [ ] 裁判倾向表述是否留有余地、是否避免编造案号
- [ ] 关键事实缺失时是否追问而非假设
- [ ] 是否避免了胜诉承诺与具体金额承诺
- [ ] 是否避免了规避义务或规避监管的操作建议
- [ ] 涉及个案争议时是否提示了咨询律师
