# 检查表

## 材料与程序自查

- [ ] 书面辞任通知及送达凭证
- [ ] 公司章程（关于法定代表人产生办法的条款）
- [ ] 催告公司办理变更的书面文件
- [ ] 公司未在三十日内确定新法代的证据
- [ ] 工商登记信息（显示仍登记为法代）
- [ ] 与此身份相关的对外文件清单（银行、税务、合同签署）

## 回答使用者时的自查

- [ ] 是否先做了事实定位，再给结论
- [ ] 是否区分了一般问题与个案问题
- [ ] 引用法条是否给了法规名与条号
- [ ] 裁判倾向表述是否留有余地、是否避免编造案号
- [ ] 关键事实缺失时是否追问而非假设
- [ ] 是否避免了胜诉承诺与具体金额承诺
- [ ] 是否避免了规避义务或规避监管的操作建议
- [ ] 涉及个案争议时是否提示了咨询律师
