# 法定代表人辞任

> 法定代表人辞任规则与涤除登记路径

## 一、快速开始（怎么用）

**装上之后这样用**：直接提问即可，例如「挂名法人怎么退出？」「辞任后公司不配合怎么办？」

**什么时候会用到它**：

- 挂名法人怎么退出
- 辞任后公司不配合怎么办
- 辞任多久生效

**回答时会怎么组织**：先判断你属于哪种情形，再给结论、法律依据、理由、建议动作和风险提示。

## 二、装完验证（确认真生效）

在对话里问一句测试问题：

```
挂名法人怎么退出？
```

**验证标准**：回答应当**先区分情形**（不同情形结论不同），再给出对应的法律依据（法规名 + 条号）。
如果它直接给一个笼统结论、不区分情形，说明技能没被正确加载，请检查技能目录是否放在正确位置。

再测一句越界问题「帮我起草一份起诉状」——期望它说明本技能只提供一般性知识、不代拟正式文书。
若它直接开始写文书，同样说明技能未生效。

## 三、适用边界（什么时候别用它）

- **法律基础**：以中国大陆现行法律为基础，法条核验日期见 `references/law.md` 页首。
- **地域**：涉及裁判倾向的表述以公开裁判文书的普遍做法为基础，各地裁判尺度可能不同。
- **时间**：法律修订后需重新核验；公司法 2023 年修订自 2024 年 7 月 1 日施行。
- **个案争议**：涉及具体金额测算、时效判断、程序选择、文书起草的，本技能只给方向，不出正式法律意见。
- **非公司法问题**：婚姻家事、知识产权、刑事、劳动争议中不涉及公司治理的部分不在范围内。
- **需要代写文书**：本技能不代拟起诉状、答辩状、代理词等正式法律文书。

## 四、适用范围

适用于担任法定代表人的董事或经理希望辞任的情形，以及辞任后公司不配合变更登记的处理路径。

## 五、判断树

先定位问题落在哪个节点，再按对应结论处理：

| 情形 | 判断标准 | 结论 |
|---|---|---|
| 谁可以担任法定代表人 | 是否为代表公司执行公司事务的董事或者经理 | 法定代表人按照公司章程的规定，由代表公司执行公司事务的董事或者经理担任 |
| 辞任的效力 | 辞任的是董事/经理职务还是仅辞去法定代表人 | 担任法定代表人的董事或者经理辞任的，视为同时辞去法定代表人 |
| 辞任何时生效 | 是否已向公司作出辞任的意思表示 | 辞任自意思表示到达公司时生效；但因此导致董事会成员低于法定人数的，需继续履职至改选完成 |
| 公司的义务 | 是否在法定期限内确定新的法定代表人 | 公司应当在法定代表人辞任之日起三十日内确定新的法定代表人 |
| 公司不配合怎么办 | 是否已催告且公司仍不办理 | 可通过诉讼请求公司办理变更登记或涤除登记 |

## 六、操作步骤

1. 书面提出辞任，明确辞去董事/经理职务（同时视为辞去法定代表人）
2. 留存辞任通知的送达凭证，固定辞任生效时间
3. 催告公司在三十日内确定新的法定代表人并办理变更登记
4. 公司不配合的，向市场监督管理部门反映情况
5. 必要时提起诉讼，请求判令公司办理变更登记或涤除登记
6. 同步处理与公司相关的其他身份（如授权代表、银行预留信息）

## 七、常见误区

- 只口头辞职，未留书面证据，无法证明辞任时间
- 以为辞去董事职务就自动不再是法定代表人，未明确意思表示
- 忽略「导致董事会成员低于法定人数时需继续履职」的例外
- 公司长期不办理变更，未及时通过诉讼或行政途径解决
- 忽略清理银行、税务等其他以法定代表人身份办理的事项

## 八、回答使用者时的要求

1. **先判断再给结论**：先确认事实落在判断树的哪个节点，再给出对应结论，不要跳过判断直接答。
2. **区分一般与个案**：一般性问题可直接回答；涉及具体金额、时效、管辖、程序选择的，说明需要结合完整材料判断。
3. **法条要引原文**：引用法条时给出法规名称与条号，原文见 `references/law.md`。
4. **裁判倾向要留有余地**：涉及裁判做法的表述用「通常」「实践中多」，不写成确定结论；不编造案号。
5. **缺材料不猜**：使用者未提供的关键事实（如公司类型、设立时间、股权结构、已履行程序），应当追问，不要假设。
6. **不做结果承诺**：不承诺胜诉、不承诺具体金额、不替代正式法律意见。
7. **不提供规避方案**：不给出规避出资义务、规避债权人保护程序、规避监管的具体操作方法。

## 九、输出格式

回答时按以下结构组织：

- **结论**：一句话给出判断
- **依据**：涉及的法条（法规名 + 条号）
- **理由**：为什么这样判断，结合使用者提供的事实
- **建议动作**：下一步该做什么，需要准备什么材料
- **风险提示**：哪些环节容易出问题，需要特别注意
